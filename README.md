## 核心原则

1. **先有词库，后有工具** — 词库是壁垒，不是工具本身
2. **先发小红书，后做工具** — 用内容验证需求，不花时间做没人要的东西
3. **先人工，后自动化** — 手动检测 50 条之后，自然知道怎么自动化
